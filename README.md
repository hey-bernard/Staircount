# Staircount 🏃

계단을 오르내리는 운동의 운동량을 기록하는 웹앱입니다. **오를 때**와 **내릴 때**를 각각 따로 카운트하고, 시간·칼로리·기록을 관리합니다.

## 주요 기능

- ⬆️ 오르기 / ⬇️ 내리기 각각 탭으로 카운트 (버튼 한 번 = 계단 1칸, 설정으로 변경 가능)
- ⏱️ 운동 시간 자동 측정 (운동 시작 ~ 종료)
- ↩️ 실행 취소로 잘못 누른 카운트 되돌리기
- 🔥 체중 기반 칼로리 소모량 추정 (오르기/내리기 별도 계수 적용)
- 📊 오늘 / 이번 주 / 누적 통계, 최근 7일 그래프
- 🗂️ 운동 기록 목록 (개별 삭제 가능)
- 💾 브라우저 로컬 저장소(localStorage)에 저장 — 별도 서버/로그인 불필요

## 사용 방법

정적 파일이라 별도 빌드 없이 바로 실행할 수 있습니다.

```bash
# 아무 정적 서버로 실행 (예시)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 브라우저로 직접 열어도 동작합니다.

## 파일 구성

- `index.html` — 마크업
- `style.css` — 스타일 (라이트/다크 모드 대응)
- `app.js` — 카운팅, 타이머, 칼로리 계산, 저장/렌더링 로직
